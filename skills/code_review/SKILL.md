code review embed
实现是否正确、简洁、优雅、高效，没有重复冗余的代码
清理不再使用的逻辑，代码
拆分重复代码为函数，复用
优化代码文件组织结构，优化各种你觉得可以优化的
异步运行时是 compio，一线程一 cpu，要利用这一点优化性能
任何 key 都可能是潜在的二进制，要从数学上避免出错的可能，并且要算法上高效，禁止用 hack 的逻辑做类型探测，要从顶层设计就解决问题
严禁 hack 编程，设计架构要有严谨的数学逻辑
各种 key 都要二进制安全，用 OPPV 编码，字符串前缀都用 enum u8 替代，删除清理 key 中的字符串和冒号
接口要支持 namespace → db，并且相互隔离
各种数据类型也一样，要杜绝穿透
数据结构要优雅高效
